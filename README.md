# Fishodoro

A focus timer set in an 8-bit fishing world. Finish a focus session, reel in a fish.

- **Stack:** Node 24 on Vercel, plain JavaScript, no build step
- **Database:** Turso (libSQL, which is SQLite-compatible). A local file in development
- **Email:** Brevo
- **Runtime dependencies:** `@libsql/client`, `@vercel/functions`, `qrcode-generator`
- **Art and sound:** generated by code. Fonts are self-hosted under the OFL

## Run locally

```sh
npm install
npm start        # http://localhost:3000
npm test
```

Locally, emails print to the console, so that's where to find verification and reset links.

`npm run dev:fast` makes each timer minute last one second, so a 25-minute session takes 25 seconds. The server refuses this mode in production or on any address other than localhost.

`npm run test:e2e` runs the browser tests and accessibility scan. It uses your installed Chrome by default. For other engines, run `npx playwright install firefox webkit`, then `BROWSER=firefox npm run test:e2e` or `BROWSER=webkit npm run test:e2e`.

## Deploy for free

All three services have free plans that need no credit card when last checked. Going over a limit stops the service rather than billing you.

1. **Turso:** sign up at turso.tech and create a database in `aws-ca-central-1` (Canada). Copy its `libsql://` URL and create an auth token.
2. **Brevo:** sign up at brevo.com, create an API key, and verify a sender address.
3. **Settings:** fill in `.env.production` (template: `.env.example`).
4. **Vercel:** run `npx vercel login`, then `npx vercel link`, add each setting with `npx vercel env add NAME production`, and deploy with `npx vercel deploy --prod`.
5. **Check it:** the page should load with its security headers, and `/server.js` and `/.env.production` should return 404.

`vercel.json` sends every request through the app so the security headers always apply, keeps the app in Montréal (`yul1`), and runs the data purge once a day.

**Limits to know:**
- Vercel's free Hobby plan is for non-commercial use, so charging money or running ads means moving to a paid plan.
- Vercel's plan allows about 1M function calls a month, and Turso's allows 500M row reads, 10M row writes and 5 GB.
- Without your own domain, Brevo sends from a shared `@brevosend.com` address, so emails may land in spam. A domain costs roughly $15 a year and fixes this.
- Turso's free plan has only one day of point-in-time restore, and deleted databases may not be recoverable.

## Before launch

- Have a lawyer review `public/legal/*`. They're plain-language drafts, not legal advice. Check the age limit (16) and the 30-day response time. They're written for an operator in Ontario under PIPEDA, so users or marketing in Quebec or the EU need another look.
- Update `CONSENT_VERSION` in `server.js` and the dates on the legal pages whenever the Terms or Privacy Policy change.

|---|---|

| `api/index.js`, `start.js` | Entry points: Vercel and local development |
| `db.js` | Schema, queries, data purge |
