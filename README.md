# Fishodoro

A focus timer set in an 8-bit fishing world. Finish a focus session, reel in a fish.

- **Stack:** Node 24.7+ with built-in `node:http` and `node:sqlite`, plain JavaScript, no build step
- **Runtime dependency:** `qrcode-generator` (for the 2FA QR code)
- **Art and sound:** generated by code. Fonts are self-hosted under the OFL

## Run locally

```sh
npm install
npm start        # http://localhost:3000
npm test
```

Locally, emails print to the console, so that's where to find verification and reset links.

`npm run dev:fast` makes each timer minute last one second, so a 25-minute session takes 25 seconds. The server refuses this mode in production or on any address other than localhost.

`npm run test:e2e` runs the browser tests and accessibility scan. It uses your installed Chrome by default. For other engines, run `npx playwright install firefox webkit`, then `BROWSER=firefox npm run test:e2e` or `BROWSER=webkit npm run test:e2e`.

## Deploy

1. Use a host with HTTPS and a persistent disk, and set `DB_PATH` to a file on that disk.
2. Fill in `.env.production` (copy it from `.env.example` if it doesn't exist) and start with `npm run start:prod`, or enter the same settings in your host's dashboard. The server refuses to start in production if a required setting is missing, including your business details.
3. Set `HOST=0.0.0.0` only if your host or container needs it, and `TRUST_PROXY=1` only behind exactly one trusted reverse proxy. Without it behind a proxy, every visitor shares one rate limit.
4. Back up the database file. Deleted accounts remain in old backups until those expire, so keep the retention short.

### Email

`MAIL_API_URL` can be any HTTP API accepting JSON `{ from, to, subject, text }` with a bearer key, such as Resend. Other providers may need a small change to `httpMailer` in `server.js`.

## Before launch

- Have a lawyer review `public/legal/*`. They're plain-language drafts, not legal advice. Check the age limit (16) and the 30-day response time. They're written for an operator in Ontario under PIPEDA, so users or marketing in Quebec or the EU need another look.
- Update `CONSENT_VERSION` in `server.js` and the dates on the legal pages whenever the Terms or Privacy Policy change.

## Layout

| Path | Purpose |
|---|---|
| `server.js` | HTTP, security headers, auth, focus and catch rules |
| `db.js` | Schema, queries, data purge |
| `public/app.js` | Timer, prefs, dialogs, Tackle Box |
| `public/account.js` | Sign-in, signup, 2FA and account forms |
| `public/world.js`, `sprites.js`, `themes.js` | Canvas world, pixel art, skies |
| `public/fish.js`, `options.js`, `password.js` | Rules shared by browser and server |
| `public/sfx.js` | Synthesized sound effects |
